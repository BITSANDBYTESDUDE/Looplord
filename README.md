# Loop Lord Portfolio

A premium interactive portfolio for **Loop Lord** — Full-Stack Developer and founder of **BITSANDBYTESDUDE**.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- GSAP + ScrollTrigger
- Lenis smooth scroll
- React Three Fiber + Three.js
- Shadcn-style UI primitives

## Features

- Immersive loading intro
- Cinematic hero section with parallax and particles
- 3D robot mascot with cursor-reactive motion
- Interactive about, skills, projects, storytelling, timeline, and contact sections
- Custom cursor and magnetic button interactions
- SEO-focused metadata setup
- Responsive layout optimized for desktop and mobile

## Local Development

```bash
npm install
npm run dev
```

## Production Commands

```bash
npm run lint
npm run build
npm run start
```
